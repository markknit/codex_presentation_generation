# CBE Lesson Plan Presentation Generation

This compatibility document supports the repository continuity skills. `AGENTS.md` contains the primary Codex operating instructions.

## Project rigor assessment

Rigor level: High.

The repository will generate classroom materials at scale. Errors can propagate across many lessons, so every deck requires source traceability, rendered inspection, native PowerPoint verification, and teacher approval before release.

## Control documents

- Current state: `STATUS.md`
- Operating workflow and environment reference: `WORKFLOW.md`
- Codex instructions: `AGENTS.md`

The active status file is `STATUS.md` on every branch. Control documents may be updated on the current branch when the change accurately describes that branch. Merge conflicts must be resolved by checking the live repository state rather than choosing one side automatically.
